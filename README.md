# Garments Factory MIS & Operational Performance Analytics

## Project Overview

A data-driven analytics project for analyzing garment manufacturing operations and providing management-level insights into production, quality, cutting, and operational performance.

## Tools & Technologies

- PostgreSQL / SQL
- Python
- Pandas
- Power BI
- Excel

## Project Components

- Data analysis using SQL
- Data analysis using Python and Pandas
- Production performance analysis
- Planned vs Actual production analysis
- Production line performance analysis
- Productivity bottleneck analysis
- Quality and defect analysis
- Cutting performance analysis
- Power BI dashboard

## Key Business Questions

- How does actual production compare with planned production?
- Which production lines have the highest and lowest efficiency?
- Where are the major productivity bottlenecks?
- What is the overall defect rate?
- Which production areas require improvement?
